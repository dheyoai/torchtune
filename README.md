# Torchtune setup for DheyoAI

```
git clone git@github.com:dheyoai/torchtune.git
```

```
pip install .
```

## For AMD GPUs
```
pip install --pre --upgrade torch torchvision torchao --index-url https://download.pytorch.org/whl/nightly/rocm6.4
```
